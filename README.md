# Mini Turn-Based Game

🎮 Play: https://calamityforsight.itch.io/mini-turnbased-game  
🌐 Portfolio: https://MiniDevCreator.github.io  

A polished, beginner-friendly **turn-based strategy game** built with **Godot 3.x**.  
This project was created as a Practice piece to demonstrate core game development skills, clean project structure, and fundamental turn-based mechanics.

## Game Overview

In this mini turn-based game, the player and enemy take turns performing actions such as attacking and defending. The game focuses on clarity, readable UI, and structured logic rather than complex visuals, making it an ideal showcase of gameplay fundamentals.

Core goals of the project:
- Demonstrate turn-based combat flow
- Practice clean scene and script organization
- Create a complete, finished game suitable for portfolio presentation

## Features

- Turn-based player vs enemy combat
- Health system with visual feedback
- Clear turn order and state handling
- Simple, readable UI
- Modular and beginner-friendly codebase
- Designed to be easily expandable
